# dev-core deltas from Core v0.1.1

Each entry records where `dev-core` differs from the vendored Core text.
Allowed types: `rephrase`, `compress`, `tighten` (D-001). Relaxing Core is
always a defect. Relaxing a project tightening that is stricter than Core is
for the user to decide.

No-regression definition (Issue #68, card I68-C7a, D-021). When this pack
changes a project tightening through a reviewed change, the tightening keeps
its protection if the same risk is still stopped at the same or an earlier
public gate, with the same coverage and the same independence. A step that
only reruns a check whose input a deterministic check proves unchanged, and
so adds no protection, need not stay; the user confirms that judgment, and it
is recorded. Any other weakening is a loosening: only the user decides it,
and the record gives the source, the quote, the authority, the reason and the
scope. A run never uses this definition to skip a step.

The Evidence column cites observed
effects from the review records for possible feedback to Core
(`docs/core-feedback.md`). An empty cell means no evidence is recorded yet.
